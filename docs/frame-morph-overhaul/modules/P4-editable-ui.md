# P4 · 可编辑 UI 模块

> 上级总揽：[../README.md](../README.md)
> 目标：给用户"调这一层动效"的直接手柄，面板做减法。
> 状态：⚪ 未开始（依赖 P0 的 MotionPlan 可编辑数据）

## 模块目标

痛点③的 UI 侧。当前编辑区只能改静态几何（X/Y/宽/高/圆角/透明度）+ 整体切 recipe；面板塞满诊断/门禁/采样等调试信息。P4 让动效可局部细调、实时预览，主界面回归"选方案 / 调这层 / 看预览"。

## 规划的功能清单

| #   | 功能                                                            | 状态      |
| --- | --------------------------------------------------------------- | --------- |
| 1   | per-layer 动效编辑：写入 MotionTrack，不再整体 applyRecipe 重算 | ⚪ 未开始 |
| 2   | 时间轴：拖拽调 delay / duration                                 | ⚪ 未开始 |
| 3   | 缓动曲线可视化编辑                                              | ⚪ 未开始 |
| 4   | 单图层动效类型下拉                                              | ⚪ 未开始 |
| 5   | personality 滑杆（energy / bounce / sharpness）                 | ⚪ 未开始 |
| 6   | 面板做减法：诊断/门禁/采样收进「高级/调试」折叠抽屉             | ⚪ 未开始 |
| 7   | 用户改动保留：重新生成时保留 `source:"user"` 的 track           | ⚪ 未开始 |
